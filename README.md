# D3: Data-Driven Documents

<a href="https://d3js.org">
  <img src="./docs/public/logo.svg" width="256" height="256" alt="D3 Logo">
</a>

**D3** (or **D3.js**) is a free, open-source JavaScript library for building data-driven visualizations using open web standards.  
Its low-level, unopinionated approach offers exceptional flexibility for creating dynamic, interactive graphics on the web.

For more than a decade, D3 has powered award-winning visualizations, influenced countless higher-level charting libraries, and supported a vibrant global community of data practitioners.
